Long description
----------------
EN
RingCast Player turns an LG TV into a digital signage screen managed from RingCast Manager,
a self-hosted signage server for businesses: lobby screens, menu boards, notices and
schedules.

How it works:
1. Enter the address of your organisation's signage server (for example
   https://signage.example.com).
2. The TV shows a pairing code. An administrator adds the screen in the server's dashboard
   with that code.
3. The TV plays whatever the server assigns to it, full screen, and keeps playing if the
   network drops for a while.

Requirements: a RingCast Manager server reachable from the TV, with a certificate
from a public certificate authority. RingCast Player does not include content or a server of its
own and is not useful without one.

No accounts, payments or advertising in the app. The app collects no personal data: it
stores its pairing with the server on the TV and sends technical details of the screen (model,
software version, network address) only to the server you enter.

ES
RingCast Player convierte un televisor LG en una pantalla de señalización digital gestionada desde
RingCast Manager, un servidor de señalización autoalojado para empresas: pantallas de
recepción, cartas de menú, avisos y horarios.

Cómo funciona:
1. Introduzca la dirección del servidor de señalización de su organización (por ejemplo
   https://signage.example.com).
2. El televisor muestra un código de vinculación. Un administrador añade la pantalla en el
   panel del servidor con ese código.
3. El televisor reproduce a pantalla completa lo que el servidor le asigna, y sigue
   reproduciendo aunque la red se corte un rato.

Requisitos: un servidor RingCast Manager accesible desde el televisor, con un
certificado de una autoridad de certificación pública. RingCast Player no incluye contenido ni un
servidor propio y no es útil sin uno.

La aplicación no tiene cuentas, pagos ni publicidad. No recoge datos personales: guarda en el
televisor su vinculación con el servidor y envía datos técnicos de la pantalla (modelo,
versión del software, dirección de red) solo al servidor que usted introduce.
