RingCast is the screen app for NetRing Signage Manager, a signage server that businesses run
for themselves. The app needs such a server; for the review use our test server
https://signage.netringtech.com. Adding the screen is done in the server's dashboard in a web
browser on a computer or phone (any modern browser), with the test account above. There is
no account, sign-in, payment or advertising in the app itself.

On the TV (remote keys in brackets):
1. Open RingCast. The splash appears, then "Connect to your signage server" with the
   address field focused.
2. [OK] opens the on-screen keyboard. Type signage.netringtech.com after "https://", so the
   field reads https://signage.netringtech.com. Select "Done" on the keyboard [OK]: the
   keyboard closes and Connect has the focus.
   With the Magic Remote you can also point at Connect and press [OK].
3. [OK] on Connect. After "Connecting…" the TV shows a pairing code, for example HXRT-2B99.

In the browser:
4. Open https://signage.netringtech.com and sign in with the test account.
5. Choose Screens > Add Screen, type the code shown on the TV, check the details (model
   "LG ..."), give the screen a name and confirm.

On the TV:
6. Within a few seconds the TV shows "Screen added", the name and the account. After a
   60-second countdown the sample content plays full screen.

Things to try:
- [BACK] while playing leaves the app (webOS shows the previous app or the home screen).
  Opening RingCast again plays at once, without setup. On a test TV nothing brings it back
  automatically; on a signage installation the organisation's server can (see the UX
  scenario, section 5).
- [BACK] on the address screen at first launch leaves the app.
- On the pairing code screen, [OK] or [BLUE] (or pointing at the button at the bottom left and
  pressing [OK]) opens the address screen with the current server; [BACK] returns to the code.
- [EXIT] closes the app; [HOME] opens the home screen. Colour and number keys do nothing.
- Turn the TV off and on, or unplug it: RingCast keeps its setup and plays again when opened.
- Disconnect the network while playing: the content keeps playing with a small "Offline"
  marker; reconnect and the marker goes away.
- A wrong address (for example http://example.com or 192.0.2.10) is refused with the reason.

To test again from the start: in the dashboard, Screens, the screen's Commands menu > Remove
screen. The TV shows a new pairing code by itself.
